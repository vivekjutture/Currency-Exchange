A high-performance **Single Page Application (SPA)** designed to handle real-time currency conversions. This project demonstrates proficiency in **React hooks**, **API integration**, and **responsive UI development**.

---

## 🔍 Project Overview

The Currency Exchange Web App allows users to:
- Input an amount
- Select a base currency
- Select a target currency
- Instantly view the converted value using live exchange rates

This project is ideal for showcasing **frontend fundamentals**, **API consumption**, and **clean UI logic** in a real-world use case.

---

## ✨ Features

- 🔄 Real-time currency conversion
- 🌍 Supports multiple global currencies
- ⚡ Instant results without page reload
- 🧠 API-based data fetching
- 🖥️ Simple, intuitive user interface
- 🚫 No backend required

## ⚙️ How It Works

1. User enters the amount to convert
2. Selects the source currency
3. Selects the target currency
4. JavaScript fetches the current exchange rate from an API
5. The converted amount is displayed instantly

## 🚀 Getting Started

1. **Clone the Repository**

    ```bash
    git clone https://github.com/vivekjutture/Currency-Exchange.git
    ```

2. **Navigate to the Project Directory**

    ```bash
    cd Currency-Exchange
    ```

3.  **Install dependencies**
    ```bash
    npm install
    ```

4.  **Run the local server**
    ```bash
    npm run dev
    ```

5.  **Build for production**
    ```bash
    npm run build
    ```
